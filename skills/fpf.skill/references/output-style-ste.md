# STE-inspired output style

Load this file only when `output_style = "ste"`.

- Do not use FPF-specific terms in narrative prose; use clear simplified synonyms.
- Ignore `fpf_terms_explained`.
- Use short, clear sentences with one topic per sentence.
- Prefer active voice where practical.
- Use vertical lists for complex information.
- Preserve the original meaning, evidence strength, confidence, and uncertainty.
- Treat these rules as an ASD-STE100 Issue 9-inspired overlay, not a formal-conformance claim.
