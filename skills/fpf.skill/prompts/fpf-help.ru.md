# Справка по `$fpf`

`$fpf` — один навык с графом лениво загружаемых промптов. Передайте ему прямую команду или задачу на русском либо английском языке. В дереве ниже показаны основные русские команды. Канонические английские имена также продолжают работать.

## Дерево команд

```text
$fpf
├── справка                   показать эту страницу; никогда не сохраняет отчёт
├── план                      вернуть только план вызовов; не исполняет и не сохраняет
├── скан применимости         найти релевантные паттерны FPF
├── обзор исследований        построить ограниченную карту актуальных данных
├── исследовать варианты      сгенерировать и сравнить альтернативы
├── проверка дизайна          критически проверить предложение до реализации
├── синтез решения            выбрать из оценённых альтернатив и оформить ADR
├── улучшение качества        изменить и повторно оценить версионированную цель
└── аудит согласованности     проверить реализованную или принятую работу
```

Семь аналитических команд возвращают полный результат в чате и по умолчанию сохраняют один отчёт. `$fpf справка` и `$fpf план` отчёты не сохраняют.

Прямые аналитические команды: `$fpf скан применимости`, `$fpf обзор исследований`, `$fpf исследовать варианты`, `$fpf проверка дизайна`, `$fpf синтез решения`, `$fpf улучшение качества` и `$fpf аудит согласованности`.

## Объединение аналитических команд

Для одного явного последовательного запуска используйте ` + ` с пробелами:

`$fpf проверка дизайна + улучшение качества + аудит согласованности Усиль это версионированное предложение.`

Общую задачу указывайте только после последней команды. Каждая соседняя пара должна быть разрешённым переходом графа. Запуск использует одну кампанию, единый реестр находок и один итоговый отчёт. При нехватке данных, решения или полномочий на изменение он останавливается, не выдумывая разрешение и не перезапуская проверку по кругу.

Итоговый артефакт содержит один дедуплицированный список всех проблем и слабых мест в заявленных границах и профиле оценки, а также один упорядоченный список исправлений и улучшений с привязкой к находкам. Промежуточные команды не сохраняют отдельные отчёты.

## Примеры

- `$fpf справка`
- `$fpf план Нужны актуальные исследования, варианты и решение владельца.`
- `$fpf проверка дизайна Проверь эту модель области до реализации.`
- `$fpf проверка дизайна + улучшение качества Усиль это версионированное предложение.`
- `$fpf проверка дизайна + улучшение качества + аудит согласованности Исправь и проверь это предложение.`
- `$fpf аудит согласованности Проверь принятые исправления по зарегистрированным находкам.`
- `$fpf Какие паттерны FPF применимы к этому ограниченному вопросу о дизайне сервиса?`

Используйте `$fpf план`, когда нужен только рабочий процесс без исполнения аналитических промптов. Для прямой команды текст после неё становится задачей выбранного промпта. В композиции задача указывается только после последней команды.

## Язык результата

`output_language = "auto"` выбирает русский, если вызов или оставшаяся задача содержат осмысленный русский текст на кириллице; иначе выбирается английский. Значения `ru` и `en` фиксируют язык. Явная инструкция пользователя имеет приоритет над доступной настройкой проекта, а настройка — над встроенным значением. Точные команды, идентификаторы FPF, пути, код, цитаты и ссылки не переводятся.

## Режимы отчёта

По умолчанию FPF работает автономно. Файл `.fpf-runtime.toml`, создаваемый установщиком, хранит абсолютный путь к локальному репозиторию toolkit и задаёт `save_report = "on"` и `report_style = "plain"`; CAPRMEDIO устанавливать не требуется. Необязательный `.caprmedio/settings.toml` активного проекта или явная инструкция пользователя могут выбрать `report_style = "caprmedio"`, причём явная инструкция имеет приоритет. Режим CAPRMEDIO создаёт ненормативный Analysis Report Atom в самом узком доказанном Scope Unit, содержащем весь охват анализа. Если топологию или правила допуска Atom нельзя надёжно определить, сохранение прекращается без догадок.

Канонический синтаксис Codex — `$fpf`. Маршрутизатор также понимает текстовый префикс `/fpf` для переносимости между хостами, но это не регистрирует отдельную slash-команду.
