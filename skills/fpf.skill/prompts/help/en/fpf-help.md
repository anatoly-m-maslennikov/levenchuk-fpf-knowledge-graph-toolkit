# `$fpf` Help

`$fpf` applies bounded First Principles Framework patterns to framework, software, and skill-development questions. It can frame problems, recover current structure, research a field, explore options, design evaluations, challenge proposals, record decisions, improve versioned targets, and audit implemented work.

Choose one area to see its typical tasks, profiles, commands, and examples:

```text
$fpf help
├── framework
├── software
└── skills
```

- `$fpf help framework`
- `$fpf help software`
- `$fpf help skills`

Use `$fpf plan <question>` when you want a non-executing call plan. Analytical commands can be composed explicitly with ` + `; put the shared task after the final command. Help and Plan never save reports. Analytical commands return their complete artifact and follow the active standalone or CAPRMEDIO report settings.

English and Russian tasks and aliases are supported. Canonical identifiers, FPF IDs, paths, code, quotations, URLs, and citation targets remain unchanged.
