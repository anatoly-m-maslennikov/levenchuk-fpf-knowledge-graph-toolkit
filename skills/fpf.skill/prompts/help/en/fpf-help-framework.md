# `$fpf` Help — Framework Development

Use this area for framework problem definition, concepts and terminology, pattern authoring, framework architecture, editions and migrations, publication and discoverability, and framework quality or coverage.

## Typical profiles

- Framework problem and scope
- Framework concepts and terminology
- Framework pattern authoring
- Framework architecture
- Framework edition and migration
- Framework publication and discoverability
- Framework quality and coverage

## Typical calls

- `$fpf problem frame Frame the recurring problem and acceptance boundary for this framework.`
- `$fpf structure recover Recover the current framework architecture and dependency structure.`
- `$fpf options explore Compare alternative framework structures without choosing one.`
- `$fpf evaluation design Define the framework coverage evaluation and stop rules.`
- `$fpf design challenge Challenge this proposed framework pattern before publication.`
- `$fpf quality improve Improve this versioned framework artifact and re-evaluate it.`
- `$fpf alignment audit Audit the completed edition migration for semantic preservation.`

Use `$fpf plan <question>` when the task state is unclear. Recovery describes what currently obtains; Challenge examines a proposal; Audit examines implemented or accepted work.
