# Справка по `$fpf`

`$fpf` применяет ограниченный набор паттернов First Principles Framework к вопросам разработки фреймворков, программного обеспечения и навыков. Он помогает формулировать проблемы, восстанавливать текущую структуру, исследовать область, сравнивать варианты, проектировать оценку, проверять предложения, фиксировать решения, улучшать версионированные цели и проверять реализованную работу.

Выберите одну область, чтобы увидеть типичные задачи, профили, команды и примеры:

```text
$fpf help
├── Разработка фреймворков
├── Разработка ПО
└── Разработка навыков
```

- `$fpf help framework` — русский псевдоним: `$fpf справка фреймворки`
- `$fpf help software` — русский псевдоним: `$fpf справка ПО`
- `$fpf help skills` — русский псевдоним: `$fpf справка навыки`

Используйте `$fpf plan <вопрос>` (русский псевдоним: `$fpf план`), если нужен только план без исполнения. Аналитические команды можно явно объединять через ` + `; общую задачу указывайте после последней команды. Справка и План никогда не сохраняют отчёты. Аналитические команды возвращают полный артефакт и следуют активным автономным или CAPRMEDIO-настройкам отчёта.

Поддерживаются русские и английские задачи и псевдонимы. Канонические идентификаторы, FPF ID, пути, код, цитаты, URL и цели ссылок не переводятся.
