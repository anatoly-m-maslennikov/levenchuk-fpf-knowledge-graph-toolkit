Use this route when the package is already being applied and one of its source, evaluation, or carrier assumptions changes.

1. Revisit a source when a missing, stale or contradicted claim could change the narrative's use. Use `G.2` for a renewed SoTA synthesis; compare an ordinary event record or fictional canon directly.
2. Return to [[NSTD/20_06_Declared-Use Narrative Rendering Quality Evaluation/00_NSTD.06 - Declared-Use Narrative Rendering Quality Evaluation|NSTD.6]] when the evaluated object kind, declared use, value meaning, quality characteristic, evidence basis, or low-value repair route changes.
3. Use `E.22` when the improvement question is underframed: purpose, floor, protected trade-offs, expected evidence, result form, or cost and risk are not explicit.
4. Use `E.23` only for an exact changed narrative rendering version or declared changed slice with [[NSTD/20_06_Declared-Use Narrative Rendering Quality Evaluation/00_NSTD.06 - Declared-Use Narrative Rendering Quality Evaluation|NSTD.6]] re-evaluation planned.
5. Use `G.11` refresh when FPF Core edition, generated-narrative practice, reader telemetry, teaching-test evidence, source pack, or the [[NSTD/20_06_Declared-Use Narrative Rendering Quality Evaluation/00_NSTD.06 - Declared-Use Narrative Rendering Quality Evaluation|NSTD.6]] evaluation characteristic space changes.
6. Distinguish the teaching or narrative product from observations about its use. Reuse an observation only for the claim and conditions it actually supports; a worked example may remain in the pattern that explains the method.
